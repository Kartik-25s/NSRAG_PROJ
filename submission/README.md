# NSRAG Submission Files

- `nsrag_submission_deck.pptx`: presentation deck for the current project status.
- `nsrag_paper.tex`: paper draft describing the codebase and achieved results as of now.
- `assets/nsrag_architecture.png`: shared architecture figure used by the paper and deck.
- `assets/nsrag_results_overview.png`: shared results chart used by the paper and deck.
- `generate_nsrag_submission.py`: script that regenerates the deck and figures from the repo metrics files.
